# eclipse settings

## formatter

- eclipse > settings > java > code style > formatter
- Import ecuacion-internal-lib-tools/checkstyle/eclipse-java-google-style_ecuacion_changed.xml

## import

- Set eclipse > settings > java > code style > organize imports
- Delete java, javax, ... (everything) in organize imports window, and import classes will be ordered alphabetically.る

## shortcut key

- Select eclipse > settings > general > keys > content assist, and Set the operation in Binding box.
